# Using Cortex

Cortex is one front door for campus questions: ask in plain language and it works
out which department's documents to answer from, then shows the sources it used.

One message can cover several topics at once — each part gets its own labelled
section with citations. If a question is too vague to route, the assistant asks
before guessing, and if nothing in the knowledge base covers it, it says so
instead of inventing an answer.
