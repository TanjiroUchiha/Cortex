# WiFi and network access

Campus WiFi (the EDU-CAMPUS network) uses your institute ID and password. Hostel blocks have a separate network that is registered per device.

If WiFi is down in a whole area, check the IT status page first — campus-wide outages are posted there. For a single room or seat with no coverage, report the location through the IT help portal under network issues.

VPN access for remote systems (placement portal internals, licensed research tools) requires the remote access request form on the IT portal plus manager or faculty approval. VPN accounts are reviewed every semester and unused ones are revoked.

Wired ports in labs and offices are activated on request; damaged ports or loose connections are network faults, not facilities issues.
