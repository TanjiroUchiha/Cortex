# Shelter-in-place notice

## Steps
1. Confirm that the request concerns shelter-in-place notice and identify the responsible unit.
2. Submit the relevant record identifier and supporting evidence through the Security Operations Desk.
3. Save the case reference and check the portal for a decision or a request for clarification.
4. If the record remains unresolved after the stated service window, contact security@cdu.example with the existing reference.

## Rule
When directed, occupants secure doors, silence devices and follow official updates; leaving the shelter area requires an all-clear or responder instruction. The responsible owner is Campus Security. Submit a case through the Security Operations Desk with the relevant record identifier, date and supporting evidence; keep the generated case reference until the status is closed.

## Exception
Do not create a duplicate request while an existing case is under review; urgent safety or privacy risks use the designated emergency channel.
