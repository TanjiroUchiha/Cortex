# Event infrastructure and power request

## Steps
1. Confirm that the request concerns event infrastructure and power request and identify the responsible unit.
2. Submit the relevant record identifier and supporting evidence through the Facilities Service Desk.
3. Save the case reference and check the portal for a decision or a request for clarification.
4. If the record remains unresolved after the stated service window, contact facilities@cdu.example with the existing reference.

## Rule
Event organizers submit a site plan, expected attendance and electrical load estimate at least ten working days before setup. The responsible owner is Facilities. Submit a case through the Facilities Service Desk with the relevant record identifier, date and supporting evidence; keep the generated case reference until the status is closed.

## Exception
Do not create a duplicate request while an existing case is under review; urgent safety or privacy risks use the designated emergency channel.
