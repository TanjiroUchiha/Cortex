# Software Licenses

Software licenses and installations

Institute-licensed software — Microsoft 365, MATLAB, SPSS and approved developer tools — is installed by the IT team only; personal copies are not permitted on lab machines. Raise a request on the IT help portal under software, naming the tool, the course or project it is needed for, and the lab or laptop it goes on.

Requests are reviewed within two working days; licensed installs happen remotely over the campus network — the machine just needs to be on and connected. Open-source tools can be self-installed on personal laptops but not on lab systems.

Report a failed install, expired license or activation error to the IT Help Desk — it-helpdesk@campus.edu (ext 4123) — with a screenshot of the error.
