# Computer labs

Lab machines run a managed image — personal software cannot be installed and files saved to the desktop are wiped on restart. Save work to the cloud drive or a personal USB.

Report a lab machine that will not start, crashes, has a dead monitor or missing peripherals through the IT help portal with the lab name and the machine number printed on the monitor bezel.

Specialised lab software (statistical tools, CAD, simulators) is installed by IT before each semester; requests mid-semester need the lab incharge's approval on the portal.

Lab booking for project work outside timetable hours goes through the department timetable coordinator, not IT.
