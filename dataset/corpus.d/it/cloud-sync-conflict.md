# Cloud file sync conflict recovery

## Summary
**What should the reader know?** Users preserve both versions, record the affected folder and open an IT ticket; do not delete the conflict copy before review.

## Action
Use the IT Service Desk for a case-specific answer. The service desk at it@cdu.example can route a request but cannot approve an exception outside its delegated role.

This record applies to institution-managed accounts and devices; system-owner approval is required for privileged access.
