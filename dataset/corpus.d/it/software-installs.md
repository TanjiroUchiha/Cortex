# Software installation and licenses

Licensed software is installed through the IT self-service portal on institute-owned machines only.

Available titles include the standard office suite, development tools, statistics packages and CAD software licensed for lab use. Requests are reviewed within two working days; unusually expensive licenses need a faculty sponsor.

Personal laptops can use the student licenses listed on the IT portal (office suite, antivirus, and the research tools that permit home use). Software must be removed when you leave the institute.

Report installations that fail, licenses that expire early, or software that will not activate through the help portal with the machine name shown on its asset tag.
