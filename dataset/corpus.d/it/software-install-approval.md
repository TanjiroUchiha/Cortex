# Software installation approval

## Steps
1. Confirm that the request concerns software installation approval and identify the responsible unit.
2. Submit the relevant record identifier and supporting evidence through the IT Service Desk.
3. Save the case reference and check the portal for a decision or a request for clarification.
4. If the record remains unresolved after the stated service window, contact it@cdu.example with the existing reference.

## Rule
Requests name the software, version, business or course need and device; IT checks licensing and security before deployment. The responsible owner is Information Technology. Submit a case through the IT Service Desk with the relevant record identifier, date and supporting evidence; keep the generated case reference until the status is closed.

## Exception
Do not create a duplicate request while an existing case is under review; urgent safety or privacy risks use the designated emergency channel.
